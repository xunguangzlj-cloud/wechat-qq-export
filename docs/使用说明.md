# 使用说明

## 微信和 QQ

微信先在 Windows 客户端登录并保持运行。数据目录已迁移或探测不正确时，填写微信设置中显示的文件管理目录。输入准确备注、昵称或群名；同名时选择列表中的稳定会话身份，不默认导出第一项。

QQ 先按 [NapCat 官方说明](https://github.com/NapNeko/NapCatQQ) 配置已登录的本机服务，再在工具 QQ 入口填 HTTP 地址和访问令牌。服务和 QQ 需要另外安装；工具不包含它们，也不提供账号凭据。

批量入口每行输入一个会话，选择同名候选后继续。增量导出需继续使用原输出目录，目录按平台、账号和会话身份区分。更换目录会建立新记录库。缺失的本地媒体会记录原因，不能恢复服务器已删除或未同步到本机的内容。

## 日期和粘贴

默认最近 7 天，点击下拉可选日期；也可选今天、昨天、最近 30 天、本月、上月、全部，或输入 `YYYY-MM-DD HH:MM:SS`。所有时间均为北京时间。结束日期包含当日，精确结束时刻不包含该时刻。名称、日期和路径支持右键剪切、复制、粘贴、全选。

## 公众号文章

- **浏览器页面**：每行粘贴一个原文链接，使用 Chrome / Edge 独立临时实例打开。页面验证需要用户手动完成，正文可见后按提示继续。只读取本次页面，不使用日常浏览器配置。
- **文章链接**：直接请求无需验证的公开正文；浏览器能打开而直接请求失败时，改用浏览器入口。
- **导入已保存网页**：正文可见后通过浏览器另存为 HTML / MHTML，再导入。正文未保存完整会报告原因，不执行网页脚本。
- **微信本地消息链接**：输入公众号名或会话 ID，读取本机已有消息中的文章链接，不代表全部公众号历史。
- **WeRSS 已采集历史**：先由用户部署服务、授权、添加订阅并完成采集。工具仅读取已有文章。AK / SK 保留在当前窗口内存，不写入文章文件。

文章按发布时间筛选，旧文章先选“全部时间”。默认增量跳过已保存正文；需要重新抓取作者修改内容时关闭增量。图片缺失保留状态和原因。TXT / JSON 在正文原位置保留图片标记，Markdown 使用相对路径引用图片。预览时请选择文章 JSON 或对应入口。

## 语音和结果检查

语音解码使用固定版本 rust-silk，成品已包含；语音转文字默认关闭，首次启用需下载模型。识别在本机执行，准确性受录音和语言影响，重要内容仍需校对。

导出后查看报告中的覆盖范围、失败原因和未知发送者。只包含本机能读取的数据；未知身份不会凭昵称推断为“我”。上传给大模型前自行检查需要分享的内容。
