# 参考项目与实现关系

本项目以实际可接入的公开接口和源码为依据，星数随时间变化，不把高星等同于当前可用性。

| 项目 | 本项目的使用方式 |
| --- | --- |
| [wechat-chat-export](https://github.com/zhuzhangxue/wechat-chat-export) | Apache-2.0 源码派生基线；保留许可证及署名 |
| [wechatauto-replica](https://github.com/fanyuantaier/wechatauto-replica) | 固定 1.2.4.4 依赖，读取本地 Windows 微信数据库 |
| [NapCatQQ](https://github.com/NapNeko/NapCatQQ) | 独立编写 OneBot HTTP 适配；不复制或打包服务代码 |
| [qq-chat-exporter](https://github.com/shuakami/qq-chat-exporter) | 研究分页、时间过滤及附件组织思路；未复制 GPL 实现 |
| [WeRSS](https://github.com/rachelos/we-mp-rss) | 读取用户已部署服务中的订阅和文章；不执行授权、添加订阅或刷新 |
| [rust-silk](https://github.com/Wangnov/rust-silk) | 固定 v0.1.3 Windows 解码组件，下载校验 SHA-256 |
| [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) | 本地 SenseVoice 语音识别，模型另外下载 |

各依赖的具体版本、许可与上游地址见 [第三方声明](../THIRD_PARTY_NOTICES.md)。公众号正文、浏览器采集、导入、批量和增量模块自行实现；外部项目历史能力和登录权限不能推断为本工具自动具备的能力。
